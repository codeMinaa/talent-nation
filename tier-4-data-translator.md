# TIER 4 — DATA TRANSLATOR

## 1. Introduction

The purpose of this tier is to understand how computers represent different types of information and why data must be represented in a format computers can process.

## 2. Customer Information

The bank has the following customer information:

| Information | Value |
|---|---|
| Customer Name | Victor |
| Age | 30 |
| Account Balance | ₦150,000.50 |
| Account Active | Yes |

## 3. Identifying Data Types

Each piece of information belongs to a data type.

| Information | Data Type | Explanation |
|---|---|---|
| Victor | String | Represents text or characters. |
| 30 | Integer | Represents a whole number. |
| 150000.50 | Float | Represents a number with a decimal point. |
| Yes | Boolean | Represents a true or false value. |

## 4. How Computers Represent Information

Computers use binary as their basic representation system.

Binary uses only two digits:

- 0
- 1

Computers represent information using these binary digits.

For example:
- Text is represented using character encodings.
- Numbers are represented using binary numerical formats.
- Boolean values represent states such as True or False.

This allows computers to store, process, and communicate information.

## 5. What Happens When Data Is Incorrect?

Imagine a customer's actual account balance is ₦150,000.50, but the bank system incorrectly interprets it as ₦15,000.50.

This could cause several problems:

1. It could make the customer's available funds appear lower than they really are.
2. The customer might be unable to access some of their money.
3. It could create misunderstandings between the customer and the bank.
4. It could lead to financial errors and loss of trust.

This shows why accurate data representation is important.

## 6. Why Must Computers Convert Information?

Computers must convert information into a form they can understand because their hardware processes information using binary digits (0 and 1).

This allows computers to store, process, and produce information.

## 7. Key Lessons Learned

- Different information belongs to different data types.
- Strings represent text.
- Integers represent whole numbers.
- Floats represent decimal numbers.
- Booleans represent true or false values.
- Computers use binary to represent information.
- Incorrect data can lead to serious errors.

## 8. Conclusion

I have learned that computers do not understand information exactly as humans do. They use representations and instructions to store and process data. Understanding data types and binary is an important foundation in programming.

# Where Do We See Code?
Code is everywhere around you, even if you don't realize it. When you:

Open a banking app and see your balance
Send a WhatsApp message
Search for something on Google
Watch a video on YouTube
Use a calculator on your phone
You're interacting with code. Someone wrote instructions that tell the computer how to display your balance, how to send your message, how to search for information, and how to play your video.


What Does Code Look Like?
Code looks like a set of written instructions. Here's an example:

price = 100
discount = 20
final_price = price - discount
print(final_price)

# What is a Programming Language?
A programming language is a system of rules and symbols that allows humans to write instructions that computers can execute.

Language	Designed For
Python	  General purpose, readability, AI, data science
JavaScript	Web development (running in browsers)
Java	Enterprise applications, Android apps
C	System programming, operating systems
C++	Game development, performance-critical applications
Go	Cloud infrastructure, high-performance servers
Rust	Systems programming, memory safety



# COMMON MISTAKES
Misconception: "Learning Python means learning the Python syntax first."

Reality: The syntax of a language is how you express programming concepts. Focus on understanding the concepts first — the syntax will become natural with practice.

Misconception: "Code is just random symbols that only experts understand."

Reality: Code is structured, logical, and follows clear rules. Anyone can learn to read and write code with practice.
